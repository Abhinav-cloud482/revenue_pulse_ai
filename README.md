# revenue_pulse_ai
RevenuePulse AI is an enterprise-grade platform featuring 100k+ transaction processing, XGBoost &amp; Prophet revenue forecasting, K-Means customer segmentation, and Isolation Forest anomaly detection.


## RevenuePulse AI

RevenuePulse AI is an enterprise business intelligence and revenue prediction platform designed for retail stores, startups, and e-commerce businesses. It processes large transaction datasets to forecast future revenue, analyze seasonal trends, segment customers, and detect sales anomalies.




## Key Features


* High-Volume Data Processing: Supports ingestion and aggregation of large datasets exceeding 100,000 transaction rows.

* XGBoost Revenue Prediction: Utilizes regression models to project 30-day and 90-day future business revenue.

* Prophet Time-Series Forecasting: Decomposes seasonal trends and establishes confidence intervals for predictive timelines.

* K-Means Customer Segmentation: Categorizes user bases into RFM (Recency, Frequency, Monetary) personas such as champions and loyal regulars.

* Isolation Forest Anomaly Detection: Flags unusual sales spikes and sudden dips in real time.

* Executive PDF Reporting: Generates summaries ready for preview, printing, and export.




## Tech Stack

* Frontend: React 18, Vite

* Styling: Tailwind CSS

* Visualizations: Recharts

* Icons: Lucide React




## Quick Start Guide

1. Clone the repository:

```
Bash
git clone https://github.com/Abhinav-cloud482/revenue-pulse-ai.git
cd revenue-pulse-ai
```

2. Install dependencies:

```
Bash
npm install
```

3. Start the development server:

```
Bash
npm run dev
```

4. Build for production:

```
Bash
npm run build
```
